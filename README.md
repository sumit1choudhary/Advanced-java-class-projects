# Advanced Java Projects

This repository contains a collection of Advanced Java projects developed to practice Java programming, database connectivity, networking, GUI development, and web application development.

## Projects Included

### 1. Calculator
A calculator application developed using Java to perform basic arithmetic operations.

### 2. Client-Server
Demonstrates client-server communication and networking concepts in Java.

### 3. DBConnect
Demonstrates database connectivity using Java Database Connectivity (JDBC) to connect Java applications with a database.

### 4. GUI
Contains Java Graphical User Interface applications using GUI components such as buttons, labels, text fields, and frames.

### 5. RMI
Demonstrates Remote Method Invocation (RMI), which allows a Java application to invoke methods on objects running on another Java Virtual Machine.

### 6. Servlet
Contains Java Servlet programs demonstrating request handling, response generation, and server-side web application development.

### 7. ShopSphere E-Commerce Project
ShopSphere is a Java-based e-commerce web application developed using Java 17, Servlets, JSP, JDBC, and MySQL.

**Key Features:**
- User registration and login
- Product browsing
- Shopping cart management
- Checkout and order tracking
- Customer profile management
- Admin dashboard for store management

## Technologies Used

## Prerequisites

Before running the projects, install the following tools as required by each project:

- Java Development Kit (JDK)
- Eclipse IDE, IntelliJ IDEA, or VS Code
- MySQL Server for database-based projects
- Apache Tomcat for Servlet/JSP projects
- Apache Maven for Maven-based projects

## How to Run

1. Clone or download this repository.
2. Open the required project folder in your IDE.
3. Configure the JDK and required dependencies.
4. Set up the database if the project requires one.
5. Configure Apache Tomcat for web applications.
6. Build and run the project.

For Maven-based projects, run the following command from the project directory:

```bash
mvn clean package
```
